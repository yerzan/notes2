Wyjaśnienie kodu (Wersja EXE)

Ogólne Tłumaczenie Bloków

Blok 1: Definicje systemowe i sekcje danych
extern _printf, _scanf, _getchar, _exit ; Import funkcji z biblioteki C global _main ; Punkt startowy programu section .data ; Sekcja na zmienne stałe (zainicjowane) format_1 db "%d ocena: ", 0 ... ocena dq 0.0 ; Zmienne w pamięci (w wersji EXE są globalne)
Tutaj komunikuję się z systemem operacyjnym. Używam słowa extern, aby poinformować kompilator, że funkcje printf czy scanf zostaną dołączone z zewnętrznej biblioteki C podczas linkowania. W sekcji .data trzymam wszystkie zmienne globalne. Nie muszę już używać trików z call getaddr, bo mam sekcję danych, gdzie adresy są stałe.
Blok 2: Inicjalizacja (Wersja EXE)
_main: finit ; inicjalizacja koprocesora
To jest punkt wejścia programu _main. Zaczynam od finit, żeby przygotować koprocesor do obliczeń zmiennoprzecinkowych. W tym kodzie nie muszę używać sub esp, 24, ponieważ moje zmienne ocena, suma itd. są zdefiniowane globalnie w sekcji .data.
Blok 3: Główna pętla i printf (Wersja EXE)
loop1: push dword [prompt] ; wrzucam wartość zmiennej prompt na stos push format_1 ; wrzucam adres stringa format_1 call _printf ; wywołuję systemowe printf add esp, 2*4 ; sprzątam stos (2 argumenty * 4 bajty)
W pętli pobieram bezpośrednio adresy zmiennych z sekcji .data. Jest to o wiele czytelniejsze niż w wersji pod asmloader. Wrzucam argumenty na stos od prawej do lewej, wołam funkcję systemową i czyszczę stos, aby zachować porządek w pamięci.
Blok 4: Wczytywanie i sprawdzanie (scanf)
lea eax, [ocena] ; wrzucam ADRES zmiennej (scanf potrzebuje wskaźnika) push eax ; wrzucam na stos dla scanf push format_2 ; wrzucam format "%lf" call _scanf ; pobieram liczbę add esp, 2*4 ; czyszczę stos cmp eax, 1 ; czy wczytano 1 liczbę? jne error1 ; błąd -> czyść bufor
Używam scanf z biblioteki standardowej. Podaję mu adres zmiennej ocena, żeby wiedział, gdzie zapisać wczytaną liczbę. Wynik w EAX mówi mi, czy wczytanie się udało (zwraca 1). Jeśli nie, skaczę do czyszczenia bufora, aby program się nie zapętlił na błędnych danych.
Blok 5: Logika koprocesora (Warunek stopu i weryfikacja)
jmp exit1 ; skok jeśli wczytano 0.0 skip1: fstp st0 ; czyszczenie stosu FPU mov ecx, 6 ; licznik dla 6 ocen check1: fld qword [grades + ecx*8 - 8] ; ładuję ocenę z tablicy fld qword [ocena] ; ładuję ocenę wpisaną fcomip st0, st1 ; porównaj i zdejmij ze stosu je valid1 ; jeśli równe, to ocena poprawna loop check1 ; sprawdź kolejną ocenę w tablicy jmp loop1 ; jeśli żadna nie pasuje, wróć po nową ocenę
Tutaj porównuję ocenę użytkownika z tablicą dozwolonych ocen. Używam fcomip, która porównuje wartości i jednocześnie sprząta stos FPU. Jeśli znajdę pasującą wartość (je valid1), przechodzę do dodawania, w przeciwnym razie wracam do pobierania danych."
Blok 6: Obliczanie i wypisywanie wyniku
error1: call _getchar ; pobierz znak cmp al, 0x0A ; czy to Enter? jne error1 ; jeśli nie, czyść dalej jmp loop1 ; wróć po nową ocenę valid1: fld qword [suma] ; dodawanie: suma + ocena fadd qword [ocena] ; suma = suma + ocena fstp qword [suma] ; zapisz wynik inc dword [licznik] ; licznik++ inc dword [prompt] ; prompt++ jmp loop1 ; wróć po kolejną liczbę
W error1 czyszczę 'śmieci' z bufora za pomocą getchar aż do znaku nowej linii. W valid1 używam instrukcji fadd na koprocesorze, żeby bezpiecznie dodać liczbę typu double do sumy, po czym zwiększam liczniki.
Blok 7: Zakończenie
exit1: cmp dword [licznik], 0 ; czy cokolwiek wpisano? je empty1 ; jeśli nie, skocz do empty1 fld qword [suma] ; suma / licznik fild dword [licznik] ; zamiana int na double fdivp st1, st0 ; dzielenie push dword [suma+4] ; wypisywanie: wrzucam 8 bajtów (2x4) push dword [suma] ; na stos dla printf push format_3 ; format wyniku call _printf ; drukuj jmp exit0 ; koniec programu empty1: push 0, push 0, push format_3, call _printf ; drukuj średnią 0.0 exit0: push 0, call _exit ; zamknij program
Na końcu dzielę sumę przez licznik, używając fild do konwersji typu int na double. Wynik wypisuję, wrzucając go na stos w dwóch częściach po 4 bajty, ponieważ printf w systemie 32-bitowym oczekuje argumentów 4-bajtowych."
Wskazówka na obronę
Jeśli wykładowca zapyta: "Dlaczego w tej wersji nie używasz call getaddr?", odpowiedz pewnie:

"To jest wersja wykonywalna (.exe), w której mamy dostęp do sekcji .data. Dzięki temu mogę bezpośrednio odwoływać się do etykiet (format_1, ocena, suma) i nie muszę obliczać ich adresów w locie za pomocą skoków, jak to było wymagane w ograniczonym środowisku asmloadera."

Analiza Linia po Linii

Blok 1: Nagłówki i Sekcje (Konfiguracja środowiska)
[bits 32]
Deklaruję, że program ma zostać skompilowany do architektury 32-bitowej, co jest wymagane przez procesory x86.
extern _printf
Informuję asembler, że funkcja printf znajduje się w zewnętrznej bibliotece C systemu Windows i zostanie podłączona przy linkowaniu.
extern _scanf
To samo dla funkcji scanf, która obsługuje wczytywanie danych.
extern _getchar
Importuję funkcję służącą do pobierania pojedynczego znaku z bufora.
extern _exit
Importuję funkcję kończącą program w systemie operacyjnym.
global _main
Definiuję _main jako główny punkt wejścia, którego szuka Windows przy uruchamianiu programu.
section .data
Definiuję sekcję danych, w której przechowuję zmienne posiadające początkowe wartości (stałe).
format_1 db "%d ocena: ", 0
Definiuję tekst wyświetlany użytkownikowi (zakończony znakiem 0).
format_2 db "%lf", 0
Format dla scanf, oznaczający wczytanie liczby typu double (%lf).
format_3 db 0xA, "srednia: %g", 0xA, 0
Definiuję format wyniku (0xA to kod znaku nowej linii).
grades dq 2.0, 3.0, 3.5, 4.0, 4.5, 5.0
Deklaruję tablicę sześciu dozwolonych ocen (typ dq – 8 bajtów każda).
ocena dq 0.0
Rezerwuję 8 bajtów na wczytaną ocenę.
suma dq 0.0
Rezerwuję 8 bajtów na sumę ocen.
licznik dd 0
Rezerwuję 4 bajty na licznik ocen (dd – 4 bajty).
prompt dd 1
Rezerwuję 4 bajty na numer wyświetlanego pytania.
section .text
Rozpoczynam sekcję kodu, w której znajdują się właściwe instrukcje programu.
Blok 2: Inicjalizacja i Główna Pętla
_main:
Etykieta początku programu.
finit
Resetuję koprocesor matematyczny (FPU), aby wyczyścić jego rejestry.
loop1:
Etykieta początku pętli wczytywania ocen.
mov eax, [prompt]
Kopiuję numer bieżącego pytania z pamięci do rejestru EAX.
push eax
Wrzucam ten numer na stos jako argument dla printf.
push format_1
Wrzucam adres napisu zachęty na stos.
call _printf
Wywołuję systemową funkcję wyświetlającą tekst.
add esp, 2*4
Usuwam ze stosu 8 bajtów (dwa argumenty), które wrzuciłem przed chwilą.
lea eax, [ocena]
Pobieram adres zmiennej ocena (wczytywanie przez wskaźnik).
push eax
Wrzucam adres zmiennej na stos.
push format_2
Wrzucam format "%lf" na stos.
call _scanf
Wywołuję funkcję wczytującą dane od użytkownika.
add esp, 2*4
Sprzątam stos po wywołaniu scanf.
cmp eax, 1
Sprawdzam wynik scanf – powinien zwrócić 1, jeśli wczytano liczbę.
jne error1
Jeśli nie wczytano poprawnej liczby (np. wpisano litery), skaczę do obsługi błędu.
Blok 3: Logika sprawdzania danych (FPU)
fld qword [ocena]
Kładę wczytaną liczbę na wierzchołek stosu koprocesora (st0).
ftst
Porównuję wartość na szczycie FPU z zerem (0.0).
fstsw ax
Kopiuję stan koprocesora do rejestru AX.
sahf
Przenoszę flagi z AX do flag procesora CPU, aby umożliwić skoki.
jne skip1
Jeśli liczba nie jest zerem, skaczę do weryfikacji w tablicy.
fstp st0
Jeśli liczba była zerem, zdejmuję ją ze stosu FPU i kończę.
jmp exit1
Skaczę do obliczeń średniej.
skip1: fstp st0
Usuwam ocenę ze stosu FPU, bo przed chwilą tylko ją testowałem.
Blok 4: Weryfikacja oceny w tablicy
mov ecx, 6
Ustawiam licznik pętli sprawdzającej na 6 elementów.
check1:
Początek pętli porównującej wpis z tablicą.
fld qword [grades + ecx*8 - 8]
Ładuję na FPU kolejną ocenę z mojej tablicy.
fld qword [ocena]
Ładuję wpisaną ocenę na FPU.
fcomip st0, st1
Porównuję te dwie wartości i zdejmuję jeden argument ze stosu.
fstp st0
Usuwam drugi argument (sprzątam stos FPU).
je valid1
Jeśli oceny są równe, to wpisano poprawną wartość – skaczę do valid1.
loop check1
Zmniejszam ecx i jeśli nie jest zerem, wracam sprawdzić kolejną ocenę.
jmp loop1
Jeśli sprawdziłem całą tablicę i nic nie pasowało, ignoruję to i pytam ponownie.
Blok 5: Obsługa błędów i aktualizacja sumy
error1:
Tutaj czyszczę bufor wejściowy, jeśli użytkownik wpisał tekst.
call _getchar
Pobieram jeden znak z klawiatury.
cmp al, 0x0A
Sprawdzam, czy to był Enter (kod 10).
jne error1
Jeśli nie, czytam dalej aż do końca linii.
jmp loop1
Po wyczyszczeniu bufora wracam do pytania o ocenę.
valid1:
Jeśli ocena jest poprawna.
fld qword [suma]
Kładę aktualną sumę na FPU.
fadd qword [ocena]
Dodaję do niej nową ocenę.
fstp qword [suma]
Zapisuję nowy wynik w pamięci.
inc dword [licznik]
Inkrementuję licznik poprawnych ocen.
inc dword [prompt]
Inkrementuję numer pytania.
jmp loop1
Wracam do pobierania kolejnej oceny.
Blok 6: Obliczenia i wyjście
exit1:
Tu trafiam, gdy wpisano 0.
cmp dword [licznik], 0
Sprawdzam, czy cokolwiek wpisano.
je empty1
Jeśli nie, skaczę do obsługi przypadku z zerem ocen.
fld qword [suma]
Kładę sumę na FPU.
fild dword [licznik]
Ładuję licznik na FPU (konwertując go z int na double).
fdivp st1, st0
Dzielę sumę przez licznik.
fstp qword [suma]
Wynik (średnią) zapisuję z powrotem w pamięci.
push dword [suma+4]
Wrzucam wyższą połowę średniej na stos dla printf.
push dword [suma]
Wrzucam niższą połowę średniej na stos.
push format_3
Wrzucam format wyniku na stos.
call _printf
Wypisuję wynik.
add esp, 3*4
Sprzątam stos po wypisaniu wyniku.
jmp exit0
Kończę program.
empty1:
Obsługa przypadku "brak danych".
push 0, push 0
Wrzucam dwa zera na stos jako 0.0.
call _printf
Wypisuję średnią 0.0.
exit0:
Etykieta końcowa.
push 0
Kod sukcesu.
call _exit
Kończę działanie programu.
